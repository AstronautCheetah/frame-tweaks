Frame Tweaks' own fixes and app setups, written for the Steam Frame: each one tested on a
Frame and installed into your home folder, so it survives SteamOS updates and comes off cleanly.

How it's loaded: like any other pack (see [docs/mods.md](../../docs/mods.md)), one folder per
tweak, each described by the front matter of its README.md. Frame Tweaks' other official pack,
[3rd Party](../third-party/pack.md), uses the same categories. This file sets the order of the
categories (for both) and of this pack's tweaks in the installer window, the README and
`./install.sh list`.
