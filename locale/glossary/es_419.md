# Glossary and style: Spanish (Latin America), es_419

For `locale/es_419.po`. Keep to it so the translation reads as one voice; change an entry here
first, then `dev/i18n.py export es_419 DIR --all` and fix the texts that use it.

## Who reads it
Someone with a Steam Frame (Valve's VR headset running SteamOS) in Latin America, using an app
that installs fixes and apps ("tweaks"). Plain, friendly, precise, neutral Latin American Spanish
(understood from Mexico to Argentina): no vosotros, no voseo, no Spain-only words. Address the
reader as **tú** (informal), imperative: "Instala", "Haz clic", "Presiona", "Elige". Short
sentences, like the English. Keep the English tone (no marketing, no extra politeness).

## Keep exactly
- Placeholders and their count/order meaning: `%s`, `%d`, `%(name)s`, `{name}`, `{0}`, `%%`.
  A `{name}` placeholder may move within the sentence; never translate its name.
- HTML tags and attributes (`<b>`, `<a href='...'>`, `<span style=...>`, `<br>`), Markdown
  (`**bold**`, `` `code` ``, links), emoji, arrows and symbols (← ⚙ ✔ ⟳ ⬇ ↻ 🧩 📖 🧪), leading/
  trailing spaces, newlines (`\n`), trailing colons/ellipses ("…").
- Commands, paths, file names, option names, environment variables, URLs, key names (Esc, Tab,
  Ctrl, Alt, Super, PgUp, F1), button text quoted from OTHER software when Frame Tweaks can't
  know its Spanish name (keep in English, in the same quotes).
- Product and program names: Frame Tweaks, Steam, Steam Frame, SteamVR, SteamOS, Valve, KDE,
  Plasma, KWin, Dolphin, Kate, Konsole, Arrow Pad, Full Keyboard, Recline, Android Mirror,
  Android, NordVPN, Signal, Firefox, Tor Browser, VSCodium, Claude, Claude Code, Claude Desktop,
  Homebrew, Flatpak, Flathub, ydotool, scrcpy, adb, Piper, eSpeak NG, whisper.cpp, WireGuard,
  GitHub, Wi-Fi, Bluetooth, OCR, README, VPN, D-Bus, Wayland.

## Notes
- Tweak titles: translate descriptive ones ("Shared clipboard" → "Portapapeles compartido",
  "Mouse cursor fix" → "Corrección del cursor del mouse"); keep the product names above.
- Status lines are short: keep them short.
- Terminal messages: keep them concise, same punctuation style.
- If an entry is a single word whose role you can't tell, check "where".
- Never leave English untranslated unless it's a name/command/placeholder-only string; if a text
  is only a name (e.g. "Arrow Pad"), return it unchanged.
