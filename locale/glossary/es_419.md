# Glossary and style: Spanish (Latin America), es_419

For `locale/es_419.po`. Keep to it so the translation reads as one voice; change an entry here
first, then `dev/i18n.py export es_419 DIR --all` and fix the texts that use it.

**Official wording first.** When a text names something in other software (a SteamVR button, a
KDE app, an Android setting, a Steam or Claude label), use that software's own Latin American
Spanish: [es_419.terms.tsv](es_419.terms.tsv) lists the ones our texts use, made by
`dev/i18n-terms.py es_419` from SteamVR's, Steam's, Android's, Claude Desktop's and KDE's own
translations; `dev/i18n-terms.py es_419 --lookup WORD` looks up any other, and `--check` lists
our translations that differ. Where sources disagree, the software the text talks about decides
(KDE's "Preferencias del sistema" for KDE's System Settings). The table below follows them too.

## Who reads it
Someone with a Steam Frame (Valve's VR headset running SteamOS) in Latin America, using an app
that installs fixes and apps ("tweaks"). Plain, friendly, precise, neutral Latin American Spanish
(understood from Mexico to Argentina): no vosotros, no voseo, no Spain-only words. Address the
reader as **tú** (informal), imperative: "Instala", "Haz clic", "Presiona", "Elige". Short
sentences, like the English. Keep the English tone (no marketing, no extra politeness).

## Keep exactly
- Placeholders and their count/order meaning: `%s`, `%d`, `%(name)s`, `{name}`, `{0}`, `%%`.
  A `{name}` placeholder may move within the sentence; never translate its name.
- HTML tags and attributes (`<b>`, `<a href='...'>`, `<span style=...>`, `<br>`), Markdown
  (`**bold**`, `` `code` ``, links), emoji, arrows and symbols (← ⚙ ✔ ⟳ ⬇ ↻ 🧩 📖 🧪), leading/
  trailing spaces, newlines (`\n`), trailing colons/ellipses ("…").
- Commands, paths, file names, option names, environment variables, URLs, key names (Esc, Tab,
  Ctrl, Alt, Super, PgUp, F1). A button or menu item of OTHER software: its official Spanish
  (above); English only when no source has it (then in the same quotes).
- Product and program names: Frame Tweaks, Steam, Steam Frame, SteamVR, SteamOS, Valve, KDE,
  Plasma, KWin, Dolphin, Kate, Konsole, Android, NordVPN, Signal, Firefox, Tor Browser, VSCodium,
  Claude, Claude Code, Homebrew, Flatpak, Flathub, ydotool, scrcpy, adb, Piper, eSpeak NG,
  whisper.cpp, WireGuard, GitHub, Wi-Fi, Bluetooth, OCR, README, VPN, D-Bus, Wayland.
- **Frame Tweaks' own tools and tweaks are translated** (table below), everywhere they're
  named: Arrow Pad, Full Keyboard, Recline, Android Mirror, Claude Desktop and every tweak title.

## Key legends and mouse buttons
Arrow Pad's keys (context "key legend") show what Latin American keyboards print, short enough for
a key (about 6 letters); where the keyboards print a symbol, or no short word exists, the
ISO/IEC 9995-7 symbol (⌫ Backspace, ⇥ Tab, ⏎ Enter, ⇧ Shift, ⇞ ⇟ Page Up/Down, ⇱ ⇲ Home/End).
Qt's own names (`dev/i18n-terms.py es_419 --lookup PgUp`) are the long form, for tooltips.

| key | legend | | key | legend |
|---|---|---|---|---|
| Esc | Esc | | Home | Inicio |
| Tab | Tab | | End | Fin |
| Bksp | Retro | | PgUp | RePág |
| Del | Supr | | PgDn | AvPág |
| Enter | Intro | | PrtSc | ImpPt |
| Ins | Insert | | Menu | Menú |
| Shift | Mayús | | Ctrl, Alt, Super | Ctrl, Alt, Super |

The mouse keys (context "mouse button") show the initial of the word: Right → Derecho (D),
Middle → Central (C), as in "clic derecho", "clic central" (KDE, Android).

## Notes
- Tweak titles: translate descriptive ones ("Shared clipboard" → "Portapapeles compartido",
  "Mouse cursor fix" → "Corrección del cursor del mouse"); keep the product names above.
- Status lines are short: keep them short.
- Terminal messages: keep them concise, same punctuation style.
- If an entry is a single word whose role you can't tell, check "where".
- Never leave English untranslated unless it's a command, a placeholder, or a name in the "Keep
  exactly" list; a text that is only such a name comes back unchanged. Frame Tweaks' own tools
  and tweaks are translated (the table).
- The official terms are for what our text **names** in that software. A generic phrase that only
  happens to match one of theirs (Claude's "Remove them", "removed") is a suggestion; Frame Tweaks'
  own wording in this glossary ("quitar" for uninstalling) wins.
